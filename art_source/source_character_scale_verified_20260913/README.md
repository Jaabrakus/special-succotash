# Source-scaled selected-character proof

Native Godot 4.7.1, current repository `main.tscn`, selected
`res://assets/characters/modern_soldier/modern_soldier_iso.scn`, visual scale
60.48790231. This is the modern derivative, not the original ISO character mesh.

Generated by `tools/source_character_scale_regression.gd` (72 checks, 24 rendered
rear/side images) and `tools/source_character_scale_audit.gd` (actual skin/bind
CPU bounds). Full findings and reproduction details are in
`docs/SOURCE_CHARACTER_SCALE_AUDIT.md`.

Reports preserve their original capture paths under `/private/tmp`; images
with the same basenames are copied here without modification. No original
assets were overwritten. This folder is excluded from Godot imports/exports.

Known failures remain: crouch/prone skin penetrates the floor; rifle support
fingers do not form a clean grip; the prone pistol has a free raised support
hand and low firing hand. Socket-distance checks are not visual approval.
