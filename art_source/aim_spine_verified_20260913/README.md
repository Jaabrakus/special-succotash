# Aim-spine proof

Native captures are generated by `tools/aim_spine_pitch_main_regression.gd` through `main.tscn`, using the selected modern soldier, canonical equip/stance/fire/reload owners and the saved `look_pitch_presentation.json` profile.

`canonical` images use the gameplay camera. `rear` and `side` are explicitly diagnostic views of the same paused pose, not additional gameplay camera owners. Rifle and Mark23 standing/crouched/prone each show signed and neutral pitch; accepted-fire and reload suppression are separate samples. See `docs/AIM_SPINE_PITCH.md` for completed results and limitations; the presence of this folder alone is not verification.
