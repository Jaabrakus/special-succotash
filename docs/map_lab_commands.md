# Map Lab human/LLM handoff

Map Lab saves one readable document at `res://config/maps/current_map.json`. The visual editor and automation both use `SocomMapCommandService`, so a human can take over after any command without conversion or reimporting.

Every object has a stable `id`, `type`, `name`, `position`, `rotation_degrees`, `size`, `color`, and type-specific `properties`. Coordinates are Godot meters: +X right, +Y up, and -Z forward.

Supported commands:

- `place_object`
- `place_on_object`
- `place_prefab`
- `transform_object`
- `duplicate_object`
- `duplicate_group`
- `scale_group`
- `assign_group`
- `delete_object`
- `rename_object`
- `set_object_properties`
- `set_map_name`
- `set_grid_size`
- `apply_environment_preset`
- `set_environment`
- `set_gameplay`

`set_gameplay` accepts demolition match rules in `changes`: `round_time_seconds`,
`maximum_rounds`, `rounds_to_win`, `elimination_wins_round`,
`bomb_detonation_wins_round`, and `round_timeout_result`. New demolition maps use
five-minute rounds, a maximum of seven rounds, and first team to four. A round is
won by eliminating the opposing team or detonating the planted explosive; an
expired timer is a draw. `plant_time_seconds`, `defuse_time_seconds`, and
`bomb_fuse_seconds` control the complete server-owned bomb lifecycle.

SOCOM mission object types include `team_alpha_spawn`, `team_bravo_spawn`, `bomb_pickup`, `alpha_bomb_site`, and `bravo_bomb_site`. A demolition map cannot save until all required objective types are present. The same document can advertise both `demolition` and `team_deathmatch`.

Training objects include `training_dummy` and `moving_training_dummy`. Moving targets expose patrol distance, movement speed, and turn-pause properties. Their yaw rotates the patrol line. They use the gameplay hurtbox rig when the authored map opens in training gameplay.

Tactical geometry includes true wedge `ramp` pieces, segmented `curved_wall`
pieces, and deterministic `jagged_wall` pieces. Surface objects accept
`texture_path`, `surface_kind`, `roughness`, `metallic`, and `uv_scale`
properties. Built-in `concrete`, `grass`, `dirt`, and `rock` surfaces are
generated by the runtime and require no external file. Custom texture paths
stay project-relative (`res://`) so another human, agent, build, or machine sees
the same material.

The modular building kit adds `doorway_wall`, `window_wall`, `stairs`, `roof`,
and `column`. Floor Level and Floor Height provide repeatable vertical placement,
while Place on Clicked Surfaces rests a new piece on the collision surface under
the cursor. `place_on_object` exposes the deterministic version to automation by
target object id.

Reusable built-in prefabs are `tactical_room`, `guard_tower`, and `checkpoint`.
Every prefab piece receives a shared `properties.group_id`; `duplicate_group`
copies the complete structure with relative transforms intact. Humans can edit
the group id in the inspector and duplicate the group in one click.
Every object exposes exact X/Y/Z dimensions and uniform scaling. `scale_group`
resizes a complete grouped building and its relative layout around the group
center. `primitive_box`, `primitive_cylinder`, and `primitive_sphere` provide
open-ended scalable construction pieces.

Lighting presets create saved `point_light` objects with color, energy, range,
and shadow settings. Warm Lamp, Cool Flood, Red Alert, and Moon Fill use the
same placement, selection, transform, save, and runtime pipeline as geometry.

The visible Map Health Check validates the document contract, JSON round trip,
runtime object count, collision presence, and practical-light construction.

`fog_zone` authors localized dust, mist, or smoke-heavy visibility pockets using
`density`, `blend_distance`, and `priority`. The gameplay runtime blends the
active camera into the zone's density and object color, while the global map fog
remains the baseline. This is presentation-only and does not change multiplayer
authority or hit detection.

Natural environment assets include procedural `tree`, `pine_tree`, and
`rocky_mountain` objects. Trees support `canopy_layers`, `trunk_ratio`, and a
stable `variation_seed`. Mountains support `ridge_segments`,
`roughness_amount`, `peak_offset_x`, `peak_offset_z`, and `variation_seed`.
Their `size` controls the full width, height, and depth. All three types use the
same save, duplicate, transform, undo, and gameplay-runtime pipeline as tactical
geometry. Trees collide at the trunk. Mountains build a matching solid convex
collision shape.

Example command:

```json
{
  "command": "place_object",
  "type": "wall",
  "id": "courtyard_north_wall",
  "position": {"x": 0, "y": 1.5, "z": -8},
  "size": {"x": 12, "y": 3, "z": 0.3}
}
```

An agent can inspect the machine-readable contract without changing anything:

```sh
Godot --headless --path . --script res://tools/map_command_cli.gd -- --describe
```

Use `--command-file=/absolute/path/command.json --dry-run` to validate a command without saving. Remove `--dry-run` to apply it. Pass `--map=res://another/map.json` to target a different map.

Inside Map Lab, **LLM Commands** opens the same command interface. **Copy Map JSON** hands the current complete document to an agent. Undo/redo remains available after commands entered in the visual editor.

Map Lab starts fullscreen. Press **F11** to switch between fullscreen and a window. Press **Tab** or click **Full View** to hide the side panels while keeping the human action bar visible.

Use the large mode button above the map. In **Camera** mode, left-drag orbits, Shift+left-drag pans, the wheel zooms, and double-click focuses a point. In **Edit Assets** mode, click an object to select it. The action bar then shows Move, Rotate, Resize, Focus, Duplicate, and Delete. Press **N** to switch Camera/Edit mode, **F** to focus the selected object, or **Home** to frame the entire map. Middle-drag also pans, right-drag also orbits, and a middle-click without dragging cycles the detailed transform mode.

Select a solid map object to open **Surface Material**. Choose a procedural concrete, grass, dirt, or rock surface; use **Paint Surface Tint** to recolor it; or choose a PNG, JPG, or WebP texture stored inside the project. Roughness, metallic response, and texture scale save with the map and use the same material in the editor and playable runtime.

Use **Tactical Fog Zone** for authored visibility control. **Density** controls the fog while the camera is inside the zone. **Sightline Block** controls the visible dust volume from either side, so a player cannot look cleanly through a protected choke point. **Visual Layers** controls the quality of that saved effect. Fog zones never block movement or bullets.

Use **Breached Wall + Hole** for damaged architecture. Resize the wall, then set Hole Width, Hole Height, Hole Bottom, and Hole Offset X. The same compound opening and broken edge collision build in Map Lab and gameplay.
